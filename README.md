# gcloud-common-utils

Helpers for common Google Cloud tasks used by NIVA involving following parts:

 -  Storage 
 -  Pub/Sub

## Install

From PyPI (if published):
```bash
poetry install gcloud-common-utils
```

From source:
```bash
git clone https://github.com/your-org/gcloud-common-utils.git && cd gcloud-common-utils
poetry install
```

Authenticate (once):
```bash
gcloud auth application-default login
```
